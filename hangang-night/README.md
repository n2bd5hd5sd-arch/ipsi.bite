# 🌙 한강 밤 플리 (Hangang Night)

밤 한강 잔디밭에 돗자리를 펴고, 지금 듣는 노래를 나누는 3D 공간입니다.
Three.js + WebGL + CSS만으로 만든 단일 `index.html` 페이지예요.

**라이브**: https://n2bd5hd5sd-arch.github.io/ipsi.bite/hangang-night/

## 무엇이 있나요

- **밤 한강 풍경** — 달과 별, 잔물결이 흐르는 강물 위 달빛, 다리 위 불빛과 도시 스카이라인, N서울타워 실루엣
- **산책로와 잔디밭** — 가로등, 벤치, 연석, 가로등 불빛 웅덩이, 반딧불, 랜턴이 놓인 돗자리 9개와 미니 캐릭터
- **돗자리 탭** — 돗자리를 누르면 "지금 듣는 노래 / 아티스트 / 한 줄 기분" 카드가 뜨고, 유튜브 검색으로 바로 듣거나 하트를 누를 수 있어요
- **내 돗자리 펴기** — 닉네임·곡·아티스트·한 줄 기분을 적으면 잔디밭에 내 돗자리가 펼쳐지고 카메라가 그리로 이동합니다 (localStorage 저장)
- **밤 한강 ASMR** — Web Audio로 합성한 강물·밤바람 소리 ON/OFF

## 조작

- 한 손가락 드래그: 시점 회전 / 두 손가락: 확대·축소
- 돗자리 탭: 지금 듣는 노래 보기
- 하단 **내 돗자리 펴기**: 내 돗자리 놓기
- 오른쪽 아래 **↗**: 링크 공유(또는 복사)

## 구성

```
index.html            화면·UI·3D 씬 전체 (인라인 CSS/JS)
three.module.min.js   Three.js r160 (벤더링)
OrbitControls.js      Three.js OrbitControls (벤더링)
```

외부 이미지·폰트·CDN 의존이 없어서 오프라인에서도 같은 화면이 나옵니다.
텍스처(잔디, 아스팔트, 돗자리 체크무늬, 달빛 광원, 물빛 반사)는 모두 런타임에
Canvas로 그려 씁니다.

## 로컬에서 열기

```bash
python3 -m http.server 8000    # ES 모듈이라 file:// 로는 열리지 않아요
# http://localhost:8000
```
