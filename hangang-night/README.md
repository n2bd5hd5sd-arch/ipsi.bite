# 🌙 한강 밤 플리 (Hangang Night)

밤 한강 잔디밭에 돗자리를 펴고, 지금 듣는 노래를 나누는 3D 공간입니다.
Three.js + WebGL + CSS만으로 만든 단일 `index.html` 페이지예요.

**라이브**: https://n2bd5hd5sd-arch.github.io/ipsi.bite/hangang-night/

## 무엇이 있나요

- **밤 한강 풍경** — 달과 별, 잔물결이 흐르는 강물 위 달빛, 다리 위 불빛과 도시 스카이라인, N서울타워 실루엣- **산책로와 잔디밭** — 가로등, 벤치, 연석, 가로등 불빛 웅덩이, 반딧불, 랜턴이 놓인 돗자리 9개와 미니 캐릭터
- **돗자리 탭 → 30초 미리듣기** — 돗자리를 누르면 "지금 듣는 노래 / 아티스트 / 한 줄 기분" 카드가 뜨고, 앨범 커버와 함께 **iTunes 30초 미리듣기**가 바로 재생됩니다. 진행 바를 눌러 위치를 옮길 수 있고, 하트로 좋아요를 남길 수 있어요.
- **곡 검색으로 미리듣기 연결** — '내 돗자리 펴기'에서 곡 제목·아티스트를 적고 **🔍 곡 검색**을 누르면 iTunes에서 후보 3~5개가 뜨고, 고르면 그 곡의 30초 미리듣기와 앨범 커버가 내 돗자리에 붙습니다. (검색 없이 적어도 유튜브 듣기 링크는 유지)
- **내 돗자리 펴기** — 닉네임·곡·아티스트·한 줄 기분을 적으면 잔디밭에 내 돗자리가 펼쳐지고 카메라가 그리로 이동합니다 (localStorage 저장)
- **밤 한강 ASMR** — Web Audio로 합성한 강물·밤바람 소리 ON/OFF

## 조작

- 한 손가락 드래그: 시점 회전 / 두 손가락: 확대·축소
- 돗자리 탭: 지금 듣는 노래 보기
- 하단 **내 돗자리 펴기**: 내 돗자리 놓기
- 오른쪽 아래 **↗**: 링크 공유(또는 복사)

## 구성

```
index.html            화면·UI·3D 씬·미리듣기 플레이어 (인라인 CSS/JS)
three.module.min.js   Three.js r160 (벤더링)
OrbitControls.js      Three.js OrbitControls (벤더링)
```

### 미리듣기 데이터

- 기본 돗자리 9개의 `previewUrl`·`artworkUrl100`은 iTunes Search API로 실제 조회해
  `index.html`의 `PREVIEWS` 상수에 박아 두었습니다(2026-11-27 기준).
- 곡 검색과 미리듣기 자동 조회는 `itunes.apple.com/search`를 씁니다. Apple이
  `Access-Control-Allow-Origin: *`를 주기 때문에 별도 서버 없이 브라우저에서 바로 호출됩니다.
- 한국 스토어(`country=KR`)가 결과를 돌려주지 않을 때는 미국·일본 스토어로 자동으로
  넘어갑니다. (한국 앨범도 미국 스토어에 등록돼 있어 미리듣기가 나옵니다)

외부 이미지·폰트·CDN 의존이 없어서 오프라인에서도 같은 화면이 나옵니다.
텍스처(잔디, 아스팔트, 돗자리 체크무늬, 달빛 광원, 물빛 반사)는 모두 런타임에
Canvas로 그려 씁니다.
